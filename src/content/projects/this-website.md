## Overview

This website is a personal blog and portfolio. It is a static Astro site where every page is pre-rendered to HTML, content is stored as Markdown in GitHub, and publishing happens through Pages CMS. Cloudflare rebuilds and deploys the site on every change.

## Tech stack

- Astro 5 — static site generator
- Markdown — content format with content collections
- Pages CMS — editing interface
- Cloudflare Pages — hosting and rebuilds
- Inter and JetBrains Mono — typography

## Features

- Blog with pagination, categories, tags, and RSS feed
- Project portfolio with detail pages
- Light and dark themes
- Gallery with lightbox
- Design system reference pages
