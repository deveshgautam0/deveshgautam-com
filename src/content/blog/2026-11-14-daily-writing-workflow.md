## Open the CMS

Go to app.pagescms.org, sign in with GitHub, and open the deveshgautam-com repository. You will see the Blog posts collection on the dashboard.

## Create a new post

Click New, then fill in:
- Title — one clear sentence.
- Description — the summary shown on cards and in search results.
- Publish date — today by default.
- Category — pick from the list, or it becomes a URL-friendly slug automatically.
- Tags — comma-separated keywords.
- Hero image — upload a webp or jpg under 300 KB.
- Content — write the post using H2 headings so the table of contents appears.

## Save

Hit Save. Pages CMS commits the Markdown file to GitHub, Cloudflare rebuilds the site, and the post is live in about one to two minutes.

## Drafts and edits

Tick Draft to keep a post hidden while you work on it. Untick it and save again to publish. Open any post from the list to edit or delete it.

Publishing daily is about showing up, not writing perfectly. The CMS removes the friction, so all that is left is to write.
